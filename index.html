Other things I've shipped

01

Verum — Outreach Agent

An outreach agent that only sends what it can prove. It researches a company from primary sources and puts every lead through 11 checks: a named decision-maker, a published route to them, and a dated reason to write. Only then does it draft a short email built from sourced facts.

It runs unattended on scheduled cloud sessions with no memory of their own. All state lives on a git branch, so a crashed run can never double-send. It's being tested on my own company, Ranuvo, first.
